# 🏴‍☠️ Grand Line — Página fan de One Piece

Página web hecha con [Streamlit](https://streamlit.io) con diseño personalizado en CSS:
carteles de SE BUSCA animados, línea de tiempo de las sagas, ranking de recompensas,
calculadora de recompensa propia y quiz interactivo.

## Cómo ejecutarla

```bash
pip install -r requirements.txt
streamlit run app.py
```

Se abre en `http://localhost:8501`.
